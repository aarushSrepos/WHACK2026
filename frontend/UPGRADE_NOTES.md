# SpendSense frontend upgrade

- New `/simulator` page: interactive illustrative credit repayment comparisons, missed-payment explanation and persona-aware guidance.
- New wellbeing support section on the spending & wellbeing page: NHS 111, Samaritans and emergency help.
- Existing personas, payments, disputes, accessibility controls and styling preserved.
- This is a demo; it does not make real credit decisions or financial transactions.
- To run: `npm install` then `npm run dev`.
- No AI voice API is included: that would require a secure backend and API credentials.
