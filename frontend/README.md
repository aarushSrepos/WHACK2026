# frontend/

Owned by **A (frontend and accessibility)**. Create the Next.js app here:

```
npx create-next-app@latest . 
```

Point it at the API with `NEXT_PUBLIC_API_URL=http://localhost:8000` and send an
`X-Persona: priya` (or `sam`, `amara`) header on every request.

Run the backend in mock mode (see the main README) and build against it from hour 1.
